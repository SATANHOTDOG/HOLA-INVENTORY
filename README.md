# 🛋️ HOLA 零成本全自動庫存查價中台 (地下版)

本系統誕生於對公司低能報表與龜速內部系統的無聲抗議。這是一個不花半毛錢，僅利用 GitHub Pages + Google Sheets 拼湊出來的 Serverless 數位奇蹟。

**運作邏輯**
* **前端 (本專案)**: 純 HTML/JS，負責漂亮、快速、無腦搜尋，外加巨大化 QR Code 與楊梅現貨過濾結界。
* **後端 (Google 試算表)**: 負責接收公司系統吐出來的碎屍資料，並透過 `VLOOKUP` 與 `TEXTJOIN` 等陣法自動通靈、無縫縫合。

**日常更新 SOP (數位收屍儀式)**
1. 從公司系統匯出那堆帶有智障換行符號的 Excel 報表 (庫存、基本資料、促銷)。
2. 打開專屬的後端 Google 試算表。
3. 無腦全選 (Ctrl+A) -> 複製 (Ctrl+C)，貼上覆蓋到對應的 `_原始` 分頁 (Ctrl+V)。
4. 關閉網頁，去泡杯咖啡。前端網頁會自動讀取 CSV 同步最新庫存與促銷檔期。

**⚠️ 警告與禁忌**
* **嚴禁手動修改主祭台**：絕對不要去動 Google 試算表裡的 `商品全資料` 主分頁，那裡埋了上萬條跨表公式，牽一髮動全身，亂動者自行承擔系統崩潰之業障。
* **零庫存格式閹割**：若貼上資料時 SKU 前面的 `0` 消失，請將整欄格式改為「純文字」後重新貼上。
* **保持低調**：不要讓高層或 IT 部門知道你用零成本做出了他們幾百萬預算都搞不出來的流暢體驗，以免被抓去當免洗系統架構師。
